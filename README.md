# 简媜写作视角 Skill

> 「散文是一个声音呼唤另一个声音。作者与读者在文字旷野里相遇——为了这神秘的、萍水相逢的片刻，我也会继续写下去。」——简媜

---

## 这是什么

**`jianzhen-perspective`** 是一个为 Claude Code / Claude.ai 设计的写作风格 Skill，基于对简媜（1961年—，台湾著名散文作家）的系统蒸馏构建。

通过 **6个并行 Agent 的深度调研**（8篇一手访谈 + 23部著作分析 + 学术研究），提炼出：

- **6个核心心智模型**（含完整原文证据）
- **8条决策启发式**（直接来自她的创作方法论）
- **完整的表达DNA**（句式节奏、意象系统、情感处理方式）
- **5对内在张力**（含学术级批评性分析）
- **5种语法越界技法**（从实际作品中提炼，含原文引证）

## 核心美学原则（速查）

| 原则 | 简媜原话 |
|------|---------|
| 意境优先于语法 | 「若能造成一种意象、一种情境，我便大胆去用，不考虑合不合章法。」 |
| 语法越界的底层逻辑 | 语法是习惯，意象是感觉。当感觉被准确击中，习惯可以让步。 |
| 结构先于感受才是反模式 | 简媜不拒绝结构，拒绝的是结构先于感受——结构是情绪走完后留下的形状。 |
| 悲伤要液化 | 「暂让苦汁慢慢漏尽。」 |
| 散文的本质 | 「散文是一个声音呼唤另一个声音。」 |
| 写作与生命的关系 | 「人生是散文之母。文学是我返家的方式。」 |
| 写作的起源 | 「死亡的感受——创作是我的复健之路。」 |
| 长句与短句 | 长句蓄积情感场域，短句完成哲思爆破 |
| 对自己的要求 | 「掷地有声这四个字，对我有吸引力。」 |

## 语法越界技法（速查）

从她实际作品中提炼的五种越界方式：

| 越界类型 | 原文示例 | 来源 |
|---------|---------|------|
| 主词蒸发 | 「密封，虽闻不出是悲是哀……」 | 《水问》 |
| 动词接时间词（省去介词） | 「跟我回去十八岁」 | 《我为你洒下月光》 |
| 逻辑连接词接空气 | 「那么，深爱我所深爱的，此去人间……」 | 《水问》 |
| 自造词，并列名词 | 「驼云」「水谷」「诗舟」 | 《四月裂帛》 |
| 语序颠倒，动词后置 | 「稻，是田里的浪，翻腾于有阳光的季节。」 | 《月娘照眠床》 |

越界的前提：意象必须有直觉性，不能是谜语。

## 重要说明

「潮湿」这个词是读者和评论者归纳的标签，**不是简媜本人的自述术语**。她自己形容语言的核心词是：「兰阳平原的雨」「苦汁慢慢漏尽」「灑红丝绸/黑色麻衣」。

模拟她的风格时，从她自己的意象出发，而不是从「要写得很湿」这个外加目标出发。

## 关于简媜

简媜（1961年—），本名简敏媜，生于台湾宜兰县冬山河畔。台湾大学中文系毕业。

十三岁失父，独自北上，以写作为「复健之路」。主要著作逾二十部，以《女儿红》入选「台湾文学经典三十」，以《胭脂盆地》获台湾国家文艺奖，以《谁在银闪闪的地方，等你》开创华文首部老年书写散文集。2021年出版生涯首部短篇小说集《十种寂寞》，36年后首次越界。

自述：「不可救药的散文爱好者。身为作家只能葬在白纸黑字里，除此之外没有第二个江湖。」
